PROJECT OVERVIEW

Process & Reflection.

For this project, I was tasked with reviewing and modifying existing HTML and JavaScript code to develop a customized quiz. I chose to create a quiz about the science of reading because of my interest in the topic. Given my limited experience with programming, I relied primarily on the provided tutorials, used TextEdit to modify the code, and hosted the finished quiz on GitHub.

I modified the JavaScript code by adding ten questions, corresponding correct answers, and unique positive responses for each correct answer. I also customized the appearance of the quiz by changing the title, background color, spacing between elements, and adding a line above the credit area. This project introduced me to the roles of HTML and JavaScript in web development and allowed me to gain experience modifying and publishing an interactive website.
