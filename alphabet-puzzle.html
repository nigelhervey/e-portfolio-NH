Alphabet Puzzle

01 / OVERVIEW

About the Project

Alphabet Puzzle is an interactive phonics project designed to help young learners develop foundational letter-sound knowledge.

The project explores how visual elements, interaction, and instructional feedback can support early literacy learning.
