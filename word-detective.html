03 / WEB DESIGN

Word Detective

Exploring foundational phonics skills through interactive word sorting.

01 / OVERVIEW

About the Project

Word Detective is an interactive phonics activity in which learners sort words according to their spelling patterns.

The activity focuses on three categories: consonant-vowel-consonant (CVC), consonant-vowel-consonant with a final silent e (CVCe), and vowel teams.

PROJECT OVERVIEW

Process & Reflection.

For this project, I was tasked with developing an interactive drag-and-drop activity using both traditional web development and AI-assisted coding. I created Word Detective, a phonics activity where students practice identifying CVC, CVCe, and vowel team spelling patterns. For the traditional version, I modified the provided code to customize the layout, colors, and shapes. I also incorporated instructional review screens, positive reinforcement, corrective feedback, hints, and a celebration.

For the AI-assisted version, I used Claude to generate code based on the elements of my traditional version. I was surprised by how closely the AI-generated activity matched what I envisioned. One particularly useful addition was a pool of words that allowed students to practice with different words each time they played.

I found AI to be particularly helpful as a learning tool during the development of the traditional version. Although AI allowed me to make changes more efficiently, I found the traditional development process to be more creatively stimulating and rewarding. This project sparked my interest in coding and made me realize how web development could provide another avenue for creativity. Moving forward, I would like to continue developing my programming skills while using AI as a support tool.
